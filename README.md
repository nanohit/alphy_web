# alphy.chat — лендинг

Ванильный порт макета «Alphy v2» из Claude Design: без фреймворков, зависимостей и сборки.

```
index.html     бутстрап (~2 КБ, ~1 КБ gzip) — единственное, что раздаёт Vercel
vercel.json    редиректы легаси-чата на chat.alphy.chat
cdn/           вся статика; её раздаёт jsDelivr прямо из GitHub
  alphy.css    стили
  alphy.js     разметка, логика, WebGL-«океан», SVG-глобус, данные
  benchmarks.js      ленивый SVG-график сравнения моделей
  benchmarks-data.js публичный снимок результатов и профилей затрат
  logos/       логотипы клиентов
release.sh     выпуск новой версии
```

`index.html` подключает `alphy.min.css` и `alphy.min.js` с
`cdn.jsdelivr.net/gh/nanohit/alphy_web@<тег>/cdn/`. Файлов `.min` в репозитории нет:
jsDelivr минифицирует их сам (terser и clean-css). На `localhost` бутстрап берёт
неминифицированные файлы из `./cdn/`.

## Локально

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080.

## Первый запуск

1. Создать **публичный** репозиторий `github.com/nanohit/alphy_web` (jsDelivr `/gh/`
   работает только с публичными), запушить и поставить тег `1.0.0`:
   `git tag 1.0.0 && git push origin main 1.0.0`.
2. Vercel: импортировать репозиторий. Preset — Other, build command не нужен.
   `.vercelignore` оставляет в деплое только `index.html` и `vercel.json`.
3. Домены (DNS в Porkbun):
   - `chat.alphy.chat` → Render-сервис `alphy-chat` (legacy видеочат): Custom Domain
     в Render и `CNAME chat → alphy-chat-o07d.onrender.com`;
   - `alphy.chat` и `www.alphy.chat` → Vercel-проект `alphy-web`:
     `A @ → 216.198.79.1`, `A @ → 64.29.17.1`,
     `CNAME www → ac0dc15c4bc9f6c9.vercel-dns-017.com`.

## Новая версия

Правим `cdn/` и запускаем:

```bash
./release.sh 1.0.1
```

Скрипт переписывает тег в `index.html`, коммитит и пушит коммит вместе с тегом
(`--atomic`). Vercel передеплоит бутстрап, а jsDelivr отдаст новую статику. Версии на
jsDelivr по тегу неизменяемы и кэшируются навсегда, поэтому каждая выкладка — новый тег.

## Редиректы легаси (`vercel.json`)

| Запрос на alphy.chat | Куда                                    |
| -------------------- | --------------------------------------- |
| `/1234`              | `chat.alphy.chat/1234` (308)            |
| `/room/1234`         | `chat.alphy.chat/1234` (308)            |
| `/?room=…`           | `chat.alphy.chat/?room=…` (307)         |
| любой другой путь    | тот же путь на `chat.alphy.chat` (307)  |
| `/`                  | лендинг                                 |
| `www.alphy.chat/*`   | тот же путь на `alphy.chat` (308)       |

## Настройки в `cdn/alphy.js`

- `API_ENDPOINT` — свой endpoint для демо-панели (POST `{prompt, stream:false}`).
  Если пусто, панель ходит в Groq.
- `SHOW_DEMO_ANSWER` — `false`: панель стартует с плашки «API не подключён».
- `GROQ_KEYS`, `GROQ_MODEL` — ключи (по кругу) и модель для живого демо.

## Отличия от макета

Десктоп (шире 1080 px) сохраняет стиль исходного макета. Мобильная и планшетная
вёрстка (1080 / 860 / 560 px) своя, проверена на 320–440 px в WebKit и Chromium:

- схема роутинга: приложение → вопрос → две ветки к карточкам провайдеров рядом
  (по макету из Figma);
- таблица моделей компактная: от заголовка до конца таблицы помещается в экран,
  колонка с моделью закреплена, метрики листаются вбок;
- логотипы клиентов в одну строку, «океан» — фоном за заголовком на мобильной версии;
  демка идёт через 24 px после кнопок, логотипы — под демкой;
- иллюстрации облачной платформы перестраиваются под ширину и не обрезаются;
- поля ввода на тач-устройствах 16 px, иначе iOS зумит страницу при фокусе.

Остальные намеренные изменения:

- `GROQ_MODEL`: `llama-3.1-8b-instant` Groq больше не отдаёт (404), заменена на
  `qwen/qwen3.8-27b`.
- Пакеты на глобусе анимируются из JS через stroke-dashoffset; динамических SVG-градиентов и масок больше нет.
- «Начать обучение» открывает окно входа.
- Пристыкованная справа демо-панель в раскрытом виде уезжала под следующие секции и
  схлопывалась от любого клика, в том числе по полю ввода. Теперь она поверх
  контента и закрывается кликом по шапке.
- Когда пользователь отправляет свой промпт, старый автоответ скрывается, а
  незавершённый стрим отменяется.
- Модалки закрываются по Esc; у полей формы есть `<label for>`.
- Глобус больше не встраивает шрифт в base64 (17 КБ): берёт IBM Plex Mono из Google Fonts.

Форма заявки и вход, как и в макете, ничего никуда не отправляют: только показывают
сообщение.

## Сравнение моделей

Между каталогом API и облачной платформой расположен `#model-benchmarks`.
Один SVG-график переключает шесть представлений Slopalytics:
стоимость / качество, время / качество, токены на задачу, весь расход токенов,
стоимость задачи и всего прогона. Токены на задачу доступны также в виде точек.
Есть линейная / логарифмическая шкала для точек, граница эффективности,
выбор моделей, уровень рассуждения и подсказки. Клик / тап фиксирует точку;
повторный тап, Escape, закрытие карточки или тап снаружи снимают фиксацию.
Стрелки перемещают фокус по точкам и переключателям, Home / End — к краям.

Данные: 32 варианта 8 моделей, публичный снимок 14.10.2026.
Источники: https://slopalytics.com/ и первичные страницы моделей
https://artificialanalysis.ai/models/ (Intelligence Index v4.3.2).
`python3 scripts/refresh-benchmarks.py` обновляет снимок атомарно, только после
проверки полного набора профилей. Скрипт читает данные, не исполняет удалённый JS.
В основной клиент не перенесён код React или другие зависимости Slopalytics.

Стоимость вычисляется из четырёх частей опубликованных затрат AA:
non-cache input, output, cache read, cache write. Каждая часть делится на
соответствующий исходный тариф, затем умножается на тариф из `MODELS`.
Это эквивалентный профиль расхода для перепрайсинга, а не предположение о
фиксированной пропорции входа и выхода. Отдельно сохранены профили средневзвешенной
задачи и всего прогона. Для чтения / записи кэша без отдельного тарифа используется
обычная цена входных токенов. Итог преобразует общий `rubleAmount`: тот же курс
и та же наценка 13,5%, что в каталоге. Смена тарифа Argon 1 декабря обновляет
график вместе с таблицей, сохраняя фильтры и выбранный режим.

Индекс качества, выходные токены и время — данные AA. Время относится к decode
в исходном замере, без TTFT и сетевых задержек; это не измерение API Alphy.
Отсутствующее время Argon и Mistral сохранено как null, без выдуманного значения.
Варианты Claude с fallback отмечены в подсказке. Выходные токены включают reasoning
и ответ; input / cache не подменяют показатель Total tokens исходного графика.
Подпись прямо указывает: стоимость рассчитана по ценам API Alphy.

Модуль и снимок загружаются только при приближении к графику (240 px).
Нет сетевого опроса, requestAnimationFrame, интервалов или постоянных canvas / GPU
циклов. ResizeObserver перерисовывает SVG только при смене ширины. Подсказки
обновляют текущую точку и 8 групп, а не весь график. Одно короткое появление SVG
при переключении отключено при prefers-reduced-motion. На телефоне оси строятся
в CSS-пикселях; подписи сохраняют размер, панель моделей перемещается под график.


## Календарь активности

После BARS расположен `#activity`: 7 × 26 ячеек, последние 182 календарных дня
по московской дате. `makeActivityDays` генерирует синтетические данные с фиксированным
seed для каждого дня; основные типы событий распределены равномерно по
абсолютным блокам из 35 дней. Событие у конкретной даты не меняется при сдвиге
видимого окна. Библиотека из 60 шаблонов, 10 направлений и числовых вариаций
работает без даты окончания, в том числе через год и в високосный год. Яркость
показывает суммарное число событий, типы перечисляются только в подсказке.

Первое появление в экране: пиксельное `alphy` на 2,2 секунды, затем плавная смена цветов
в тех же ячейках за 1,6 секунды. Сетка белая/серая, без перемещений, второго слоя
пикселей и Web Animations API. React и другие зависимости не нужны.
Сетка компактная: справа от заголовка на десктопе, под ним на телефоне;
все 26 столбцов помещаются по ширине. Над сеткой отображается сумма
`day.total`; это число вычисляется по тем же данным,
что используются в подсказках. Ширина до 580 px на десктопе и по доступной ширине
на телефоне; размер сетки задан явно, у кнопок отключён нативный appearance,
поэтому их минимальные размеры в Safari не растягивают и не обрезают сетку.
Наведение, тап, фокус и resize не завершают вступление досрочно.
До конца анимации сетка inert, подсказки включаются только в `is-ready`.
При `prefers-reduced-motion` смена цветов занимает 0,15 секунды.
Повторный тап / Escape / тап снаружи закрывают
подсказку. Стрелки перемещают фокус по сетке;
Home / End — по текущему столбцу.

Эффект одноразовый: IntersectionObserver отключается при запуске, используются
два таймера для вступления, нет requestAnimationFrame/интервалов и постоянных
will-change слоёв. `bindDailyRefresh` ставит один таймер на московскую полночь:
в открытой вкладке сдвигает даты, данные, подписи, счётчик и актуализирует цены.
Скрытая вкладка не держит таймер; после возврата, сна или BFCache данные
догоняют сегодняшнюю дату. Обновляются существующие 182 кнопки, вступление
не запускается повторно. При уходе со страницы таймер и его обработчики удаляются.
После вступления CSS transitions отключены. События дней делегированы на сетку,
смена фокуса обновляет две кнопки, вместо обхода всех 182 ячеек при каждом наведении.
Изолированный замер в браузере на ширине 390 px: p95 интервала между кадрами
9,1 мс во время перехода и после него, длинных задач не было. Позиции всех
182 ячеек до и после совпали; после вступления transition-duration равен 0s.

В сравнении и p50 TTFT используется одно значение `TTFT[0][2]` — 60 мс,
чтобы показатели этого замера не расходились при последующих правках.

## Фоновая нагрузка (1.4.3)

- `visibleAnimation` полностью отменяет RAF и таймер при уходе эффекта из экрана
  или скрытии вкладки / открытии модалки. После возврата анимация продолжается с места паузы; при reduced
  motion остаётся статический кадр. Учтены pagehide/pageshow и BFCache.
- Волна — максимум 15 fps, рисующий буфер не больше 480 × 200 и 65% от CSS-размера.
  Расстояние между точками сохраняется в CSS-пикселях. Размеры обновляет
  ResizeObserver, без чтения layout на каждом кадре. Шейдеры и буфер освобождаются
  при выгрузке страницы.
- Глобус — максимум 20 fps, короткие участки stroke-dashoffset вместо обновления
  radialGradient на каждом кадре. Он приглушён (opacity и маска к низу), центрирован и уходит под
  футером; кнопки находятся поверх него.
- Демо ждёт события видимости, без опроса каждые 400 мс. В свёрнутой боковой
  панели и фоновой вкладке печать и стрим приостановлены; скрытое время не
  засчитывается в скорость выдачи.
- Вращение conic-gradient у поля ввода убрано: рамка остаётся статической.
  CSS-пакеты и ветки ограничены примерно 20 изменениями в секунду и приостановлены
  вне экрана / в фоне.

Проверка в браузере, 1280 px, после прогрева, 60 секунд на `#pricing`:

| Показатель | 1.4.2 | 1.4.3 |
| --- | ---: | ---: |
| JS RAF callbacks / сек | 240 | 0 |
| WebGL draws / сек | 29 | 0 |
| Длинные задачи >50 мс | 0 | 0 |

На первом экране в 1.4.3 — 14–15 отрисовок / сек, 0,51–0,55 млн
обрабатываемых пикселей / сек вместо примерно 2,5 млн у старой волны того же
размера. Демо продолжает работать. В длительном замере JS heap колебался
в пределах 5,3–10,1 МиБ со снижением после GC; DOM в неподвижном состоянии
оставался на 1912 элементах. Это показатели страницы в тестовом браузере,
не суммарный RSS браузерного процесса. Проверочный профилировщик в релиз не включён.
